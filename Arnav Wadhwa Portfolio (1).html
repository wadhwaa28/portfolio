# About me

I'm **Arnav Wadhwa**, an 11th grader at Watkinson School.
I've been coding for six years. I build tools I wish existed,
and games I probably shouldn't have made.

## How I got here

- Year 1 → **HTML, CSS & JavaScript**. Where it started,
           and still what I ship most.
- Next   → **Python**.
- Then   → **Java**.
- Now    → **C++**.

## What I build

- **Extensions**  → QuickCite turns any page into an MLA,
                  APA or Chicago citation in one click.
- **Study tools** → Study Forge mixes spaced-repetition
                  flashcards, practice tests and an XP scoreboard.
- **Games**       → Who's That Alloy? turns metallurgy into a
                  Pokémon-style guessing game, and
                  Back Room Games is a set of small games built
                  to frustrate you into learning something.

## How I work

1. Build the thing I'd actually use.
2. Make learning feel like a game.
3. If it's frustrating, make sure it's on purpose.
4. Ship it publicly, then keep improving it.
